# Bracket Maker

Live at: http://pw-env2.eba-q3eqbj6z.us-west-2.elasticbeanstalk.com/brackets/ 

Enter the names in the field at the top and have them either randomly or entered in order into the bracket. Clicking a name advances that team to the next stage, coloring them green, and colors the other red. An optional field exists to change the title of the page, which will rename the heading and the label on the web browser tab.

This program includes implementations of 8, 16, 32, and 64 team brackets that the user can switch between. The brackets can be switched between without losing data, since the switching mechanism is just a live update of the stylesheet which hides the visibility of all elements except the ones in the selected bracket.
